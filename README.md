## Overview

This is a totally FREE biolink source, you can use this to make your own biolink and modify the source however you want.

For a moment, we are only 2 developers working on the source so please be patient.

If you want daily updates, polls, sneak peeks etc. just join the discord server and look there for anything (also for suport;) ).


## Tech Stack

| Layer | Technology |
|---|---|
| Framework | [Next.js 16](https://nextjs.org) (App Router) |
| Language | [TypeScript](https://typescriptlang.org) |
| Styling | [Tailwind CSS v4](https://tailwindcss.com) |
| Database | [Neon Postgres](https://neon.tech) (serverless) |
| ORM | [Drizzle ORM](https://orm.drizzle.team) |
| Auth | [jose](https://github.com/panva/jose) (JWT) |
| (file) Uploads | [Documentation](github.com/overmywrath/overmywrath/blob/main/kimdocs.txt) |
| Passwords | [bcryptjs](https://github.com/nicolo-ribaudo/bcryptjs) |
| Icons | [Font Awesome](https://fontawesome.com) (React) |
| Effects | [noise-gradient-bg](https://www.npmjs.com/package/noise-gradient-bg) |
